How to Check Your PC Specifications in Windows

Before upgrading a computer or asking for technical support, it helps to know what is inside it. You can check many important specifications with tools already included in Windows.

Know Your PC · Beginner-friendly guide

What are PC specifications?

Specifications (often called specs) describe the main parts and software in a computer. Useful details include the processor, installed RAM, Windows version, system type, storage capacity and graphics hardware.

Method 1: Use Settings

  1. Open the Start menu and select Settings.
  2. In Windows 11, choose System → About. In Windows 10, go to System → About.
  3. Look under Device specifications for the processor, installed RAM and system type.
  4. Look under Windows specifications for the edition and version of Windows.

The exact wording may vary slightly depending on your Windows version and language settings.

Method 2: Use Task Manager

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Select Performance. If you see a simplified window, choose More details first.
  3. Select CPU to see processor information and current speed.
  4. Select Memory to see installed memory and how much is in use.
  5. Select Disk to view drive activity and often whether Windows identifies it as an SSD or HDD.
  6. Select GPU, if shown, to view graphics information.

Method 3: Use System Information

  1. Press Windows + R on your keyboard.
  2. Type msinfo32 and press Enter.
  3. In the System Information window, look for System Manufacturer, System Model, Processor, Installed Physical Memory and BIOS information.

This is particularly useful when you need to identify the exact model of a laptop or desktop.

How to check your storage space

  1. Open File Explorer.
  2. Select This PC.
  3. Look at the available space shown beneath each drive.

For more detail, open Settings → System → Storage. Windows may show how much space is used by apps, temporary files and personal files.

What should you write down before asking for help?

  • Computer brand and model, if available
  • Windows edition and version
  • Processor name
  • Installed RAM
  • Storage type and free space, if known
  • The exact error message or problem you are experiencing
Privacy tip: If you share a screenshot of your system information online, hide serial numbers, device IDs, usernames and any other personal information first.

Final thoughts

You do not need to install a random “PC checker” app just to find basic specs. Windows' built-in Settings, Task Manager and System Information tools can answer many common questions. Never share passwords or verification codes with someone offering technical support.
